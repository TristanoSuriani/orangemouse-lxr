# Phase 9 and 10 listening checklist

Phases 9 and 10 added the mixing and tracker tools trance needs, and trance came back as version 3,
built with them. Everything here was measured for health and loudness but not listened to. Mark each
line **keep** or **change**, with a few words on what to change:

```sh
tools/render_songs.sh      # writes renders/<song>.wav (trance.wav among them)
```

The song is also in the studio's library ("Trance: Dawn Run 3"), so anything can be tried there.

## Trance: Dawn Run 3 (138 BPM, A minor, 37 s)

Measured on 2026-10-30: no clipping, nothing at the limiter, no DC; RMS -15.5 dBFS (electro -15.4).
Intro, build, breakdown, drop twice.

| What | Meant to be | Keep / change |
|---|---|---|
| The supersaw pads (VA2): held chords through the mixer's gate (x.xx.xx.x.xx.xx.) | the trance chop, in time | |
| The pump: the pads, the bass and the string pad duck under the kick | the breathing of a trance drop, not a wobble | |
| The build: the pads' filter opens over 4 bars (an effect-column slide) | a rising sweep into the breakdown | |
| The breakdown: the string pad's filter sweeps up, the anthem alone, bells, the snare roll and the riser | space, then tension | |
| The anthem (VA3 Super Lead): some notes glide in (legato) | singing, not stepped | |
| The arpeggio (Plaits Pluck), short notes | plucked, under the pads | |
| The bass: short 16ths after each beat | rolling, tight with the kick | |
| Open hats (1:2 on the last of each bar) and ghost snares (50 %) | the second drop a little different from the first | |
| The hats' EQ (+1.5 dB above 8 kHz) | bright, not harsh | |
